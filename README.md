# 📊 Student Feedback Dashboard

This project analyzes structured student feedback data to evaluate teaching effectiveness and overall student satisfaction using Power BI.

---

## 🎯 Objective

To identify key strengths and improvement areas in teaching delivery by analyzing student feedback across multiple evaluation parameters.

---

## 🧰 Tools Used

- Power BI  
- CSV Dataset  
- SQL (for data preparation)  
- Google Drive (report storage)

---

## 📂 Dataset

The dataset consists of structured student feedback responses across multiple evaluation criteria, including:

- Subject knowledge  
- Concept explanation clarity  
- Use of presentations  
- Assignment difficulty  
- Doubt-solving willingness  
- Course structure  
- Student support  
- Course relevance  

(All responses are on a numerical rating scale.)

---

## 📈 Key Insights

- Overall student satisfaction is consistently high  
- Teaching effectiveness indicators show strong performance in subject knowledge and concept clarity  
- Student sentiment is predominantly positive  
- Certain areas show scope for improvement in course structure and assignment difficulty

---

## 📝 Recommendations

- Improve course structuring with clearer weekly flow  
- Enhance student support through additional doubt-clearing sessions  
- Balance assignment difficulty to better match student skill levels  
- Increase interactivity in presentations  
- Collect mid-course feedback for early improvements
